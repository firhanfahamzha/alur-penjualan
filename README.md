# Order-to-Cash Interactive Lab

Simulasi interaktif alur penjualan untuk pelatihan. PT Firhan Fahamzha Global.

## Cara Pakai
1. Buka `index.html` di browser modern (Chrome / Edge / Firefox / Safari).
2. Tidak butuh server — bisa langsung dibuka offline.
3. Pilih mode di sidebar: **Materi**, **Roleplay**, **Puzzle**, atau **Detektif**.

## Fitur
- **Materi Alur** — 5 tahap Order-to-Cash + 20 kartu dokumen detail
- **Simulasi Peran** — Main jadi Penjual / Pembeli / Hot-seat (2 pemain)
- **Puzzle Dokumen** — Drag & drop susun urutan (3 level)
- **Detektif Audit** — Temukan error tersembunyi (15 jenis, 3 difficulty)
- **Pencapaian** — 14 badge, level system, chart skor
- **Pengaturan** — 4 tema (light/dark/sepia/auto), 3 bahasa (ID/EN/Mix)

## Fasilitator
- Tekan **Ctrl + Shift + F** untuk membuka panel fasilitator
- Atur jumlah error, seed acak, hide score, reset progress
- Export JSON / CSV / Sertifikat

## Shortcut
- `/` — Fokus pencarian
- `Ctrl + K` — Cari
- `Alt + 1..8` — Navigasi antar mode
- `Ctrl + Shift + F` — Fasilitator panel
- `Escape` — Tutup modal
